# SkillBridge

SkillBridge is a frontend prototype for an academia–industry collaboration portal. It brings together **students, industries, academicians and institutions** for skill mapping, internships and placement readiness.

## Prototype
https://companyskillsportal.lovable.app

## Features in this repository
- Responsive SkillBridge landing page
- Four role-based experience previews
- Skill-gap/readiness dashboard
- Internship recommendations
- Academia–industry collaboration feature cards
- Mobile-friendly responsive UI

## Tech stack
- React
- TypeScript
- Vite
- CSS

## Run locally
```bash
npm install
npm run dev
```

For a production build:
```bash
npm run build
```

## SIH note
This repository is a GitHub-ready frontend prototype. Backend authentication/database integrations can be added later using Supabase or another backend service.
